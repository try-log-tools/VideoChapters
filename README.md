# VideoChapters v0.1.0 β

動画に保存されたチャプター情報から、YouTube向けの時刻とタイトルの一覧を作成するWindows用アプリです。初回公開に向けた無料β版です。現在は配布準備中です。

## 確認済みの範囲

- Windows 11、Premiere 26.5.2で書き出した、Adobe XMPのチャプターマーカー入りH.264・MP4。
- 実ファイルから6個の名前と時刻を取得。出力一覧のYouTubeでの表示・ジャンプ位置は作成者が確認済み。
- Windows 10、他のPremiereバージョン、DaVinci Resolve等の実ファイルは未検証です。
- マーカー情報のない動画から、内容を推測して見出しを作る機能はありません。

## 使い方

1. 配布ZIPを展開し、同梱の利用条件を確認します。
2. VideoChapters.exeを起動します。
3. 動画をウィンドウにドロップするか、「動画を選択」で開きます。
4. 出力された時刻とタイトルを確認します。
5. 必要に応じて先頭00:00の扱いを選びます。
6. 「クリップボードにコピー」または「TXTで保存」を使用します。
7. YouTubeの説明欄に貼り付け、保存後の表示・ジャンプ位置を確認します。

## 先頭00:00の選択肢

- 変更しない：元の位置を維持します。
- 先頭に追加：元の位置を維持し、00:00の項目を追加します。
- 最初だけ変更：最初の項目のみ00:00へ変更します。他の時刻は動かしません。

元の最初の項目が7秒の場合、00:00を追加すると7秒の区間になります。10秒未満の警告が出るため、動画の内容に合わせて扱いを選んでください。秒未満は切り捨てます。

## 制限・注意

- 1回に読み込む動画は1本です。複数をドロップすると先頭の1本を読み込みます。
- 大容量または未対応ファイルの解析中は、画面の応答に時間がかかる場合があります。
- 管理者として起動すると、通常のエクスプローラーからドロップできない場合があります。
- 元動画は読み取り専用で扱います。TXTは新しいファイル名で保存してください。
- Adobe XMPの取得にはffprobeは不要です。標準チャプターの取得には別途ffprobeが必要です。初回配布での同梱範囲は配布ページの記載をご確認ください。
- 警告が出た場合は配布元とファイルを確認し、不明な場合は実行しないでください。セキュリティ機能を無効にする必要はありません。
